Acerca del sistema

Hospitalia es un prototipo académico de gestión hospitalaria desarrollado para la actividad de GitHub Fundamentals del Equipo 1.

Desarrolladora: Mariel Andrea Vargas. Tecnologías: HTML5, CSS3, JavaScript y JSON.

Los datos se almacenan únicamente en el navegador mediante localStorage. No existe servidor, autenticación ni cifrado de información clínica. No utilizar con datos personales reales ni para atención asistencial.

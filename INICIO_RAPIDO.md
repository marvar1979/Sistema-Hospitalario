# Guía de inicio rápido

1. Extraer el ZIP y abrir `Sistema_Hospitalario_Equipo1` en Visual Studio Code.
2. Abrir terminal integrada y ejecutar `python -m http.server 8080` (en Windows también `py -m http.server 8080`).
3. Visitar `http://localhost:8080` en el navegador.
4. Agregar pacientes ficticios y probar las citas.
5. Opcional: ejecutar `npm test` con Node.js instalado.
6. Seguir `github/COMANDOS_GIT.md` para iniciar Git, generar cinco commits reales, crear la rama y publicar.
7. Revisar `docs/Informe_Actividad_2.pdf`, sustituir el espacio inicial con evidencia real y completar las capturas faltantes.

Importante: el proyecto no es un sistema clínico real ni debe contener datos personales reales.
